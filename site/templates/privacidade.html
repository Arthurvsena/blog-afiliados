Política de Privacidade

O {{ site.nome }} não pede cadastro e não coleta dados pessoais como nome, e-mail ou telefone.

Links de afiliado

Ao clicar em um link para o Mercado Livre, você sai deste site. O Mercado Livre pode usar cookies para identificar que a visita veio daqui e atribuir a comissão. Consulte a política de privacidade do Mercado Livre para saber como ele trata seus dados.

Este site é hospedado pelo GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP) para segurança e funcionamento do serviço.

Seus direitos (LGPD)

Como não armazenamos dados pessoais, não há dados seus conosco para consultar ou excluir. Dúvidas podem ser enviadas pela página do projeto no GitHub.
